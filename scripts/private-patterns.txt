# Patrones que nunca deben llegar al repo público
# Formato: patrón::descripción
# Leído por: .git/hooks/pre-commit, update.sh (sanitize de skills),
#            scripts/sanitize-claude-md.sh
#
# Formato extendido: patrón::descripción[::acción]
# Separador `::` y NO `|`: los patrones de frontera contienen `|` en su
# alternación, y con `|` de separador el parser los cortaba en `(^`.
#   acción = drop   (default) -> se descarta la línea entera
#   acción = redact          -> se reemplaza el término por un placeholder y se
#                               conserva la línea (para aprendizajes técnicos que
#                               sólo mencionan de paso el nombre de un repo privado)
#
# El matcher corre `grep -liE` (case-insensitive, ERE).
#
# NO usar `\b`: el guión bajo ES carácter de palabra, así que `\bzeussalud\b`
# NO matchea `‹his-cliente›_DOC.md` — justo donde más aparecen los nombres, en
# identificadores y nombres de archivo. Costó una fuga real el 2026-07-26.
# Forma correcta, válida en ERE y en Python re:
# sin boundary, un nombre corto matchea "clausura" y "asegurar".
#
# NO agregar sistemas públicos (MIPRES, minsalud, SUIN, ADRES, PAI, SISPRO):
# son normativa/infraestructura nacional, no contexto de cliente. Bloquearlos
# sólo produce ruido y entrena a saltarse el guard.
#
# Historia: el leak del 2026-07-01 (un nombre de cliente en el bloque SESIONES) pasó
# porque esta lista tenía únicamente los placeholders de ejemplo del diseño
# original, y porque el pre-commit no cubría claude/CLAUDE.md. Ambas cosas
# corregidas el 2026-07-26.
