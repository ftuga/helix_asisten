# Patrones que nunca deben llegar al repo público — CAPA PÚBLICA
# Formato: patrón::descripción[::acción]
# Leído por: scripts/hooks/pre-commit y scripts/sanitize-private.sh
#
# Este archivo contiene sólo la MECÁNICA y patrones genéricos.
# Los nombres reales de clientes viven en `private-patterns.local.txt`,
# que está gitignored: una denylist que nombra a los clientes ES, ella misma,
# una divulgación del roster. Ambos archivos se concatenan al ejecutar.
#
# NO usar `\b` como frontera: el guión bajo ES carácter de palabra, así que
# `\bnombre\b` NO matchea `NOMBRE_DOC.md` — justo donde más aparecen los
# nombres, en identificadores y archivos. Costó una fuga real el 2026-07-26.
# Forma correcta, válida en ERE y en Python re:
#     (^|[^a-zA-Z0-9])término([^a-zA-Z0-9]|$)
#
# Separador `::` y NO `|`: los patrones de frontera contienen `|` en su
# alternación, y con `|` de separador el parser los cortaba en `(^`.
#
#   acción = drop   (default) -> descarta la línea entera
#   acción = redact          -> reemplaza el término y conserva la línea
#                               (en archivos de código se fuerza redact: borrar
#                                una línea puede romper un heredoc)
#
# NO agregar sistemas públicos (MIPRES, minsalud, SUIN, ADRES, PAI, SISPRO):
# son normativa nacional, no contexto de cliente. Bloquearlos genera ruido y
# entrena a saltarse el guard.

(^|[^a-zA-Z0-9])modulo_privado\.py([^a-zA-Z0-9]|$)::Archivo de proyecto privado::redact
contrato[[:space:]]+[0-9]{3}::Número de contrato
(^|[^a-zA-Z0-9])test1234([^a-zA-Z0-9]|$)::Credencial de test filtrada
